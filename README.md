# Aggregated Monthly Dengue Surveillance Data, Hunan Province, China, 2018–2025

This repository contains aggregated monthly dengue surveillance data supporting the study “Risk Windows, Transmission Routes, and Early Warning for Local Transmission Following Imported Dengue in Hunan Province, China, 2018–2025.”

## Data files

- `public_place_region_monthly_cases.xlsx`: Monthly aggregated dengue case counts by pseudonymized geographic area.
- `public_people_age_group_monthly_cases.xlsx`: Monthly aggregated dengue case counts by age group.

## Confidentiality protection

No individual-level records or direct personal identifiers are included. Cells containing 1–4 cases are suppressed and reported as `<5`.

Geographic administrative codes were replaced with pseudonymized area IDs. Each ID consistently represents the same geographic area throughout the dataset. The correspondence between pseudonymized area IDs and administrative areas is not publicly available.

## Temporal coverage

January 2018 to December 2025.

## Notes on data interpretation

Only observed month–category combinations are included. The absence of a row should not automatically be interpreted as zero cases.

Suppressed values (`<5`) are provided as disclosure-controlled categories and should not be treated as exact numerical counts.
